# Kategori Vitrin (Görselli Ürün Grupları) — `e3kv01` (tema-moda-3)

## Amaç
Açık temalı görselli kategori vitrini: kare görsel kart + altında kategori adı, hover'da hafif yakınlaşma ve alt çizgi vurgusu.
