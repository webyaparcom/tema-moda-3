# Urun Vitrin — `e3uv01` (tema-moda-3)

## Amaç
Musteri tarafinda modern urun vitrini. Kategori cipleriyle filtre (urunlerin category alanindan + Tumu), tam karti tiklanabilir kart (urun detay sayfasina gider), gorsel, rozetler, ad, aciklama parcasi, fiyat (yoksa gizlenir) ve sepet-widget uyumlu data-mx-* sepete ekle butonu (kart linkini tetiklemez). Canli products.json kataloğunu okur, fiyat/gorseli page/<id>/index.json detayindan zenginlestirir.
